# Sistema de Cadastro de Alunos

Sistema web desenvolvido para realizar o cadastro e a visualização de alunos.

## Objetivo

O projeto foi desenvolvido como atividade prática da disciplina Material Design Framework, aplicando conceitos de Git, GitHub, HTML5, CSS3, JavaScript, organização de projeto e trabalho colaborativo.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Estrutura do Projeto

```text
sistema-cadastro-alunos/
├── README.md
├── index.html
├── login.html
├── css/
│   └── style.css
├── js/
│   └── app.js
└── img/
```

## Funcionalidades

- Cadastro de alunos;
- Exibição dos alunos cadastrados;
- Seleção de curso;
- Validação básica dos campos;
- Interface responsiva;
- Página de login desenvolvida na branch login.

## Branches

- `main`: branch principal do projeto.
- `login`: desenvolvimento da funcionalidade de login.
- `cadastro`: desenvolvimento de melhorias no cadastro.

## Como executar

1. Clone o projeto.
2. Entre na pasta `sistema-cadastro-alunos`.
3. Abra o arquivo `index.html` em um navegador.
